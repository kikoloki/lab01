WORKSPACE SETTINGS
模型与阅读空间
模型连接
未配置
连接信息保存在项目的 .env 文件，页面不会读取或显示 API 密钥。配置状态表示字段已填写，实际可用性以成功问答为准。
文档如何处理
  • PDF 原文件和解析索引保存在本机。
  • 解析、翻页和导出无需调用模型。
  • 提问时，仅当前文档的检索结果与原文片段发送给已配置的模型服务。
  • 收藏和本次浏览器的问答记录保存在本机浏览器。
目前支持
文字型 PDF，单份不超过 25 MB、400 页。扫描件请先 OCR。文本定位基于 PDF 文字层，暂不恢复复杂表格与公式结构。


A LITTLE GUIDE
三步开始一次阅读
  1. 01
    添加一份材料
    上传自己的 PDF，或从首页打开原创示例。
  2. 02
    并排核对原文
    翻页、缩放，点击右侧文本查看左侧对应位置。
  3. 03
    带着出处提问
    切换 AI 问答，提出具体问题。点击回答里的页码回到原文，还可以展开实际工具调用记录。
快捷键：⌘ / Ctrl + U 上传 · ⌘ / Ctrl + Enter 发送问题
